## 1. ข้อมูลจาก Add Task ที่ไปโผล่ในหน้า Workspace

ปัญหาเดิม: หน้า Add Task ให้เลือกความสำคัญ / ป้ายกำกับ / ผู้ร่วมงาน / ไฟล์แนบ ได้ แต่พอสร้างงานแล้วหน้ารายการ บอร์ด และภาพรวมไม่แสดงอะไรเลย

| หน้า | สิ่งที่เพิ่ม |
|---|---|
| แท็บ "งาน" (รายการ) | แถบข้อมูลใต้ชื่องาน: ความสำคัญ, ป้ายกำกับ (แสดง 3 อัน + จำนวนที่เหลือ), อวาตาร์ผู้ร่วมงาน, จำนวนไฟล์แนบ |
| แท็บ "บอร์ด" (Kanban) | แถบข้อมูลเดียวกันบนการ์ดทุกใบ |
| ภาพรวม › งานในโปรเจกต์ | แถบข้อมูลเดียวกันใต้ชื่องาน |
| แท็บ "งาน" (แถบกรอง) | ช่องค้นหาชื่อ/รายละเอียด, กรองตามความสำคัญ, กรองตามป้ายกำกับ, ปุ่ม "ล้างตัวกรอง" |

## 2. แก้ไขรายละเอียดงานหลังสร้าง (หน้าทำงานของแต่ละงาน)

การ์ด **"รายละเอียดงาน"** ใหม่ในหน้าทำงาน แก้ได้:

- ระดับความสำคัญ (ไม่ระบุ / ต่ำ / ปกติ / สูง / เร่งด่วน)
- วันที่เริ่ม และกำหนดส่ง (ตรวจว่ากำหนดส่งต้องไม่ก่อนวันเริ่ม ถ้าผิดมีข้อความแดงแจ้ง)
- ผู้ร่วมงาน (เลือก/ถอดได้หลายคน)
- ป้ายกำกับ: ติด/ถอด และสร้างป้ายใหม่แล้วติดให้งานนั้นทันที
- ไฟล์แนบ: ปุ่มลัด `+ Production Plan`, `+ E-SOP`, เลือกไฟล์จากเครื่อง, ลบไฟล์

กติกา:
- แก้ได้เฉพาะ ผู้รับผิดชอบหลัก, Owner หรือ Team Lead
- งานสถานะ "รอตรวจ" และ "เสร็จแล้ว" ถูกล็อก (ปุ่มจาง กดไม่ได้)
- ทุกการแก้ไขถูกบันทึกในประวัติของงานและประวัติโปรเจกต์
- ย้ายส่วน "ไฟล์แนบ" แบบอ่านอย่างเดียวเดิมออก (รวมเข้าการ์ดนี้แล้ว)

## 3. จัด Layout ให้สมดุล

- **ภาพรวม**: คอลัมน์ซ้าย/ขวาสูงเท่ากัน (การ์ดสุดท้ายของแต่ละฝั่งยืดเติม) และเอาการ์ด "ข้อมูลโปรเจกต์" ที่ซ้ำกับส่วนหัวออก
- **งาน**: กล่อง "เลือกงานจากรายการ" ยืดเต็มความสูงรายการ มีไอคอน และแผงรายละเอียดเลื่อนตามหน้าจอ (sticky)
- **ทีม / สิ่งที่ส่งมอบ**: การ์ดซ้าย-ขวาสูงเท่ากัน
- **ประวัติ**: เอาการจำกัดความกว้างออก เต็มพื้นที่

## 4. ที่ทำไว้ก่อนหน้า (รอบเดียวกันของเซสชัน)

- **Kanban ลากได้**: ลากการ์ดข้ามคอลัมน์เพื่อเปลี่ยนสถานะ คลิกการ์ดเพื่อเปิดรายละเอียด
  - ยังไม่เริ่ม ⇄ กำลังทำ ย้ายได้
  - กำลังทำ → รอตรวจ ย้ายได้ (งานถูกล็อก)
  - รอตรวจ → เสร็จแล้ว เฉพาะผู้ตรวจ / Owner / Team Lead
  - รอตรวจ → กำลังทำ ต้องกรอกเหตุผลก่อน
  - ข้ามขั้น และการย้ายงานที่เสร็จแล้ว ย้ายไม่ได้ (มีแถบข้อความแจ้ง)
- **หน้าทำงานของงาน**: เช็กลิสต์ เพิ่ม/ติ๊ก/แก้/ลบ, ความคิดเห็น, บันทึกเวลา, ประวัติของงาน
- **แก้บั๊กหัวข้อ**: ไอคอนโปรเจกต์ถูกแถบสีบัง แก้ด้วย `position:relative; z-index:3`
